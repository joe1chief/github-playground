# GitHub Playground

A personal sandbox for practicing GitHub workflows and exploring GitHub profile achievements transparently.

## What belongs here

- Small documentation changes to practice branches, commits, and pull requests.
- Test issues that record a clear learning goal and outcome.
- Notes about workflow experiments and the results actually observed.

## Boundaries

This repository is for learning and experimentation only. It is not used in production and contains no production services or deployment configuration.

Keep experiments small and self-contained. Do not add secrets, private data, or fabricated contributors. Do not request reviews from unrelated people or generate bulk activity for achievements.

## Basic workflow

1. Choose a small, useful change.
2. Create a branch and make the change.
3. Open a pull request with a short explanation.
4. Check the diff and follow the repository's existing merge requirements.
5. Merge the change and record only results that can be verified.

GitHub controls achievement eligibility and award timing; completing a workflow does not guarantee a badge.
